# PSN Tracker : page Plat Wall, Implementation Plan

> **Statut :** terminé et fusionné dans `main` le 9 novembre 2026 (PR #9), tâches 1 à 8. Les cases ne sont pas cochées : la progression se lit dans `git log` et dans `docs/ETAT-DU-PROJET.md`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** remplacer « Coming soon » par le mur de tous les platines obtenus, avec Display, filtres, tri et un export PNG téléchargeable sur tout appareil.

**Architecture :** une fonction pure applique filtres et tri à la liste des platines ; la page et l'export s'en servent tous les deux. L'export est fabriqué par une route Next : `sharp` assemble les miniatures, et le texte est converti en tracés SVG avec `fontkit`, donc aucune police système n'est nécessaire sur Alpine. Rien n'est écrit sur le disque ; seule la dernière image reste en mémoire vive.

**Tech Stack :** Next.js 16 (App Router, RSC), React 19, TypeScript strict, Drizzle, sharp 0.35, fontkit 2, PGlite (tests), Vitest + @testing-library/react + jsdom.

**Spec :** [section 15](../specs/2026-11-07-psn-tracker-design.md). **Maquette validée** (référence du CSS et des dimensions) : [2026-11-09-psn-tracker-maquette-platwall.html](../specs/2026-11-09-psn-tracker-maquette-platwall.html).

## Review Focus

Chaque ligne a son test dans la tâche indiquée.

1. **Une miniature absente ou illisible sur le disque** (platine tout neuf, fichier abîmé) : la case montre l'image de remplacement et l'export réussit quand même (tâche 5).
2. **Un téléchargement après un changement de filtre ou un nouvel aperçu** : « Download PNG » donne toujours l'image de l'aperçu en cours, jamais celle d'autres réglages (tâche 6).
3. **Des filtres sans résultat** (2016 avec PS5) : la page affiche le message, « Export PNG » est inactif, l'API répond 404 (tâches 3, 6, 7).
4. **Une adresse modifiée à la main** (`?year=abc&sort=foo&show=`) : la page revient aux valeurs par défaut sans planter, l'API répond 400 (tâches 1, 6).
5. **Un nom de jeu difficile** (59 caractères, `&`, `<`, `Ⅱ`, `～`, `ō`) : jamais de case vide à la place d'une lettre, jamais de SVG cassé, 3 lignes au maximum avec « … » (tâche 4).
